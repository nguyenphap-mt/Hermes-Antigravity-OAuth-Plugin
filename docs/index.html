Troubleshooting & Knowledge

Frequently Asked Questions

Why did my Telegram agent stitch static images with FFmpeg instead of invoking Google Flow?

If an earlier attempt in the same session encountered an error (such as a 403 error before the reCAPTCHA fix), LLMs retain that failure in conversation history and proactively switch to local script fallbacks. Simply send /reset or /new in Telegram to clear historical bias; the agent will follow the bundled ai-video-generation skill and invoke video_generate natively.

What should I do if `git pull` complains about local modifications in the Hermes checkout?

Open a terminal in the hermes-agent directory and run: git stash && git pull && python install.py This safely pulls upstream changes and immediately re-synchronizes all Antigravity Suite plugins and hooks.

How does the multi-account pool handle rate-limiting (HTTP 429)?

The bridge classifies upstream errors. On detecting quota exhaustion or 429 rate limit responses, it marks the current credential as COOLING_DOWN with an exponential backoff timestamp and automatically rotates to the next available account according to your configured strategy (fill_first, round_robin, least_used).
